Privacy Policy

Application: EXIDOR Backup

Effective date: November 26, 2026

1. Application Purpose

EXIDOR Backup is a private application designed to automate the storage and recovery of business backup archives using Rclone and Google Drive.

2. Google User Data Access

The application uses the Google Drive API with the following OAuth permission:

https://www.googleapis.com/auth/drive.file

This permission allows the application to create, read, update and delete specific files authorized for use with the application.

3. Use of Google User Data

Google user data is used exclusively for:

  • Uploading backup archives.
  • Verifying uploaded files.
  • Managing backup versions.
  • Downloading archives for recovery.
  • Deleting expired backup archives.

4. Data Storage and Protection

Backup archives are stored in the authorized Google Drive account. Data is transferred using encrypted HTTPS connections.

OAuth credentials and access tokens are stored in the local Rclone configuration on the authorized computer or server.

5. Data Sharing

The application does not sell Google user data, use it for advertising, or transfer it to unrelated third parties.

6. Data Retention and Deletion

Backup archives are retained according to the retention policy configured by the authorized administrator.

The account owner may delete backup archives directly from Google Drive and revoke application access through Google Account security settings.

7. Google API Services User Data Policy

EXIDOR Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This privacy policy may be updated to reflect changes in application functionality or applicable Google API requirements.
