EXIDOR Backup

EXIDOR Backup is a private backup application designed to securely store business backup archives in Google Drive.

Application Purpose

The application uses Rclone and the Google Drive API to automatically upload, verify and restore backup archives.

Google Drive Access

The application uses the drive.file permission to manage backup files created by the application. It is intended for authorized private use only.

Privacy and Security

The application does not sell Google user data or use it for advertising.
